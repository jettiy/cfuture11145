# 시그널톡 사용자 가이드 (신규 유저용)

이 문서는 **새로 가입한 유저가 바로 서비스를 사용할 수 있도록** “무엇을 어디서 어떻게 하면 되는지”만 빠르게 정리한 가이드입니다.  
앱은 기본적으로 루트(`/`) 접속 시 `/login`으로 이동합니다.

---

## 1) 시작하기 (가입/로그인)

- **회원가입**: `/signup`
  - **아이디/비밀번호/닉네임** 입력
  - **아이디 중복 확인** 버튼을 눌러 사용 가능 여부 확인
  - 가입 성공 시 자동으로 `/app`으로 이동
- **로그인**: `/login`
  - 로그인 성공 시 `/app`으로 이동

---

## 2) 메인 화면(`/app`) 구성 (처음 보는 화면 안내)

`/app`은 크게 3개 영역으로 구성됩니다.

- **좌측**: 최근 시그널 목록 + 핵심 이슈(뉴스)
- **중앙**: AI 분석 패널 + “종목 중심 의사결정 보드”
- **우측**: 실시간 유저 채팅

상단의 **종목 탭**에서 다음 심볼을 바꿔가며 볼 수 있습니다.

- 나스닥선물: `NQ1!`
- 항셍선물: `HSI1!`
- 골드선물: `GOLD`
- 원유선물: `CL1!`

---

## 3) 실시간 채팅 사용법 (일반 채팅 vs AI 호출)

### 일반 채팅 (공개)

- 채팅 입력창에 일반 문장을 입력하면 **같은 채널 접속자 모두에게 실시간으로 공유**됩니다.
- 다른 유저들과 실시간 대화를 하려면 **@로 시작하지 않게** 입력하세요.

### AI 호출 (개인화/비공개)

- 메시지가 **`@`로 시작하면 AI 호출**로 처리됩니다.
- **중요**: `@`로 시작하는 메시지와 AI 답변은 **나에게만 보입니다.** (다른 유저에게는 전송되지 않음)
- 화면에서는 “🔒 나에게만 보이는 AI 답변입니다” 표시와 함께 **보라색 톤**으로 구분됩니다.

#### 자주 쓰는 예시

- `@브리핑 오늘 시장 요약해줘`
- `@테슬라 주가 왜 움직였어?`
- `@엔비디아 실적 요약`
- `@애플 뉴스 알려줘`

---

## 4) 설정(`/app/settings`) — 닉네임 변경

- **닉네임 변경**이 가능합니다.
- 닉네임은 **중복 불가**입니다.
- PRO 유저의 경우 시그널 계산 관련 옵션이 추가로 노출될 수 있습니다.

---

## 5) PRO 업그레이드 흐름 (신규 유저가 가장 헷갈리는 부분)

### PRO 신청

- `/app/pro-upgrade`에서 이름/연락처/이메일을 입력 후 신청합니다.
- 신청 완료 후 자동으로 **상담 페이지(`/app/support`)**로 이동합니다.

### 상담(지원) 페이지

- 일반 유저: `/app/support`에서 **내 상담 채팅**을 확인/메시지 전송할 수 있습니다.
- 관리자: `/app/support`에서 **PRO 요청 목록**과 상담 메시지를 통합 관리합니다.

---

## 6) 관리자(Admin)용: 유저 권한 변경 & 상담 관리

### 관리자 대시보드

- `/admin` (관리자 권한 필요)
- 기능:
  - **사용자 목록 조회/검색**
  - **권한 변경**: member ↔ pro ↔ admin
  - **계정 삭제(밴)**
  - **상담 관리(지원 채팅)** 확인 및 응답

### 최초 관리자 계정 (로컬/개발 환경)

프로젝트에 포함된 백엔드 문서 기준으로, 초기 테스트용 관리자 계정/생성 스크립트가 있습니다.

- 관리자 생성: `backend/create_admin.py`
- 문서 참고: `backend/README_SETUP.md`, `RUN.md`

---

## 7) 자주 발생하는 문제 해결(FAQ)

- **로그인이 안 돼요**
  - 아이디/비밀번호 오타 확인
  - 계정이 없으면 `/signup`에서 회원가입

- **실시간 채팅이 안 보여요 / 끊겨요**
  - 네트워크 상태 확인
  - 새로고침 후 재접속
  - (운영자용) 백엔드 WebSocket이 실행 중인지 확인

- **AI 답변이 다른 사람에게 보이나요?**
  - `@`로 시작하는 메시지의 경우 **나에게만 보이도록 처리**되어 있습니다.
  - 일반 채팅( `@`로 시작하지 않음 )은 **전체 공개**입니다.

---

## 8) 빠른 체크리스트 (신규 유저 30초 온보딩)

- **(1)** `/signup`에서 가입 → `/app` 진입
- **(2)** 상단에서 종목 선택 (예: 나스닥선물)
- **(3)** 오른쪽 채팅에서 일반 대화 입력(공개)
- **(4)** `@브리핑 ...` 또는 `@종목명 ...` 입력(AI 비공개)
- **(5)** 필요하면 `/app/pro-upgrade` → `/app/support`로 상담 진행
